🎯 Что умеет система

1. Семантическая обфускация трафика

· Разбивает пакеты на блоки разного размера
· Трансформирует каждый блок уникальным способом
· Меняет временные интервалы (pacing) как у реального браузера

2. Pattern-Aware Encryption

Выбирает алгоритм шифрования в зависимости от содержимого:

· TLS-like (имитация браузера)
· WireGuard-like (рандомизированные размеры)
· HTTP2-like (семантические фреймы)
· Гибридный режим

3. Защита от активного зондирования

· Обнаруживает зонды по частоте запросов
· Отвечает "скучным" 404 вместо ошибок туннеля
· Использует honeypot-паттерны

4. Адаптивная маскировка

· Выбирает уровень маскировки под ситуацию
· Кэширует результаты для быстродействия
· Контролирует задержку (5-75 мс)

🚀 Быстрый старт

Установка

```bash
# Клонируем
git clone https://github.com/your-username/semantic-obfuscator.git
cd semantic-obfuscator

# Устанавливаем зависимости
pip install -r requirements.txt
```

Запуск

```python
from main import SemanticAntiDPISystem

# Создаем систему
system = SemanticAntiDPISystem()

# Обрабатываем пакет
packet = b"GET /index.html HTTP/1.1"
context = {"client": "192.168.1.100", "flow_id": "test-001"}

result = system.process_packet(packet, context)
print(f"Оригинал: {packet}")
print(f"Результат: {result.hex()}")
```

🧠 Как это работает (упрощенно)

Семантический конвейер

```
Входящий пакет
    ↓
1. Сверх внутренне (иерархический анализ)
    ↓
2. Подразделений рассредотачивает (фрагментация)
    ↓
3. Соединяет (гибридная агрегация)
    ↓
4. Ведомо направленно (управляемая маршрутизация)
    ↓
5. Различимо отличимо (дифференциальное кодирование)
    ↓
Обфусцированный пакет
```

Каждый шаг использует семантику содержимого, а не просто байты.
